# 功能

每个定下来的功能一个文件夹：`F<NNN>-<slug>/`，例如 `F003-csv-export/`。`<slug>` 用小写英文和连字符，分支名和文件名里都会用到它。

- 编号逐个加一，用过的不再用：`F001`、`F002`……
- 每个文件夹里有一份从 `_template/plan.md` 复制来的 `plan.md`。需要时加一个 `refs/` 文件夹，放截图、示例或链接；它们是参考资料，不是需求。
- 任务卡编号 `F<NNN>-T<NN>`，写在 `pipe/cowork/latest.md` 的「下一步」。
- 功能做完或范围变了，更新方案的状态行和「结果」一节，以及 `roadmap.md`「接下来」里的表。
- 还没定的想法放 `roadmap.md` 的「以后再说」，不放这里。
