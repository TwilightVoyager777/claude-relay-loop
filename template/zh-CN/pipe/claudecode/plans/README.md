# 实现计划

一张任务卡一份计划，由 Claude Code 主会话写，子会话执行。

文件名：`YYYY-MM-DD-F<NNN>-T<NN>-<slug>.md`，例如 `2026-10-14-F003-T01-csv-export.md`。

装了 superpowers 插件，就用它的 `writing-plans` 技能写计划；没装就用下面的骨架。子会话手里只有这份计划和 `CLAUDE.md` 里的规则，所以要写到一个毫无上下文的人也能照着做。

~~~markdown
# F<NNN>-T<NN> <标题> — 实现计划

任务卡：F<NNN>-T<NN>（pipe/cowork/latest.md › 下一步）· 功能方案：features/F<NNN>-<slug>/plan.md
分支：feat/F<NNN>-T<NN>-<slug>（从 main 的 <提交> 拉出）
目标：<一句话>

## 和功能方案不一致的地方
| # | 功能方案写的 | 本计划的做法 | 为什么 |
|---|---|---|---|

## 任务

### 任务 1：<名字>
文件：<要新建或修改的确切路径>
步骤：
1. 写一个会失败的测试：<代码，或准确的描述>
2. 跑 <命令>，应当失败，报 <信息>。
3. 实现：<代码，或准确的描述>
4. 跑 <命令>，应当 <N> 条通过。
5. 更新 pipe/claudecode/latest.md 和当天日志，和这个任务的改动一起提交：`<提交信息>`。

### 任务 N：全量检查和交接
1. 跑 <全量测试命令>，应当看到 <各项条数>。
2. 写 pipe/claudecode/latest.md（偏离、没验证的地方、问题）和当天日志，并提交。
3. 停下，向主会话汇报。
~~~
