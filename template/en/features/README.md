# Features

One folder per decided feature: `F<NNN>-<slug>/`, e.g. `F003-csv-export/`.

- Numbers go up by one and are never reused: `F001`, `F002`, …
- Each folder has a `plan.md` copied from `_template/plan.md`. Add a `refs/` folder for screenshots, examples or links when useful; they are reference material, not requirements.
- Task cards are numbered `F<NNN>-T<NN>` and live in `pipe/cowork/latest.md` › Next.
- When a feature is done or its scope changes, update the plan's Status line and Results section, and the Next table in `roadmap.md`.
- Ideas that aren't decided go in `roadmap.md` › Later, not here.
